# Getting help

- **How do I…?** Start with [the docs](https://inkan-dev.vercel.app/docs). The tutorial
  (`npx @vxnsin/inkan learn`) and the examples (`npx @vxnsin/inkan examples`) cover a lot.
- **A question the docs don't answer?** Open an issue and say what you tried. A question that
  wasn't answered by the docs usually means the docs need a line more, so it's worth asking.
- **A bug?** Open an issue with the version, what you expected and what happened, ideally with
  the smallest code that shows it.
- **A security problem?** Don't open an issue; see [SECURITY.md](SECURITY.md).
